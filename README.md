# 지금 카페인

마신 음료를 기록하고, 몸에 남아 있을 것으로 추정되는 카페인량을 확인하는 앱입니다.

음료를 간편하게 기록하고, 오늘의 섭취량과 시간에 따른 예상 잔존량을 살펴볼 수 있어요. 카페인량은 추정치이며, 개인차가 있을 수 있어요.
