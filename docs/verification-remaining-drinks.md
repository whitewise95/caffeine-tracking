# 홈 음료별 추정 잔존 카페인

2026-10-04. 홈의 미래 잔존량 아래에 음료별 목록을 추가했다. 아이콘, 음료명, 현지 섭취 날짜·시각, 현재 추정 잔존량을 표시한다. 같은 음료의 여러 섭취 기록은 합치지 않고 최신 섭취순으로 보여준다. 이전 날짜도 계산에 포함한다.

기존 `remainingCaffeine` 함수를 기록별로 사용하며 홈과 동일한 시각·반감기를 전달한다. 기존 30초 갱신 및 앱 포커스·표시 상태 변경 때 함께 갱신된다. 반감기나 저장 구조는 변경하지 않았다.

목록은 반올림 전 1mg 이상인 기록만 표시한다. 이 기준은 화면 정리용이며 제거 완료나 생리적 기준을 뜻하지 않는다. 더 적은 양도 전체 홈 추정치에는 포함되며 기록 데이터는 보존한다. 미래·잘못된 기록은 기존 계산 함수가 제외한다. 목록이 비면 빈 상태를 표시한다.

검증: 설치 상태 확인, 린트 및 TypeScript/Vite 빌드 통과. 단위 테스트 5개 파일 99개, 모바일 브라우저 전체 테스트 68개 통과. 375px·390px, 어두운·밝은 테마, 200% 글자 확대, 날짜 구분, 시간 경과에 따른 수치 감소와 목록 제외를 확인했다. 토스 실제 기기 검증은 포함하지 않는다.
