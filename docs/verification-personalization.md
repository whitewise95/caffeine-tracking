최종 E2E 이후 변경은 미래의 응답 수정 시각을 학습에 사용하지 않는 순수 모델 경계 검사 한 줄이며, 이에 대한 회귀 테스트를 포함해 85개 단위 테스트·lint·build를 다시 통과했다. Toss SDK 어댑터는 변경하지 않았고, 이번 작업에서 `.ait` 재생성·업로드·실제 토스 기기 검증은 수행하지 않았다.

## 검증 범위

- 수동 반감기 슬라이더와 저장 경로 제거. PK 5시간 고정, 구버전 수동 값은 이력으로만 보관.
- v1→v2 변환 시 섭취 기록·커스텀 음료 유지, 읽기 중 원본 저장소를 덮어쓰지 않음. 새 저장 실패 시 기존 데이터 유지.
- 미래 기록 제외, 여러 섭취량 합산, 자정 연속성, 잘못된 시각·용량 입력.
- 전날 선택형 체크인, 최초 관측 구간 우선, 사전에 표시한 예측이 있어야 순서형 비교 노출.
- 모르겠음·건너뛰기·교란 제외, 중복 제출 방지, 재실행 후 같은 체크인 반복 방지.
- 구간 손실·순서형 손실의 방향, 규제·갱신 범위, 상충 관측 보류, 시간대·오랜 공백·40일 연속 사용.
- 예측 당시 기준/후보/단순 비교 값 동결, 미래 응답·미래 수정·기록 변경에 의한 평가 오염 방지.
- 피드백 수정·삭제 시 기여 재생, 학습 이력 변경 시 현재 예측 제외, 기본 복원 및 학습만 초기화.
- 예측을 먼저 화면에 표시한 뒤 노출 저장. 화면 표시 전에 이동하면 저장 취소, 느린 저장 중 이동과 실패 후 명시적 재시도.
- 체크인 응답 전후 홈 mg 동일. 기본 음료·커스텀 음료 생성, 새로고침, 수정·삭제, 캘린더 미래 숨김, Sheet 뒤로가기 유지.
- 라이트·다크, 200% 글자 확대, 레이블·키보드 포커스, 48px 터치 영역, 가로 overflow 검사.

## 검토 중 수정한 사항

ISO 오프셋 정규화, 비구간 응답의 불필요한 필드, 모델이 거부한 입력의 저장 성공 오인, 추가 섭취가 있는 관측, 긴 공백 뒤 예전 보정 복귀, 수정된 학습 이력의 예측 재사용, 실제 화면 노출 전 저장을 보완했다. 모델·통합 코드는 별도 에이전트가 읽기 전용으로 검토했다.

첫 병렬 브라우저 실행에서는 공용 테스트 서버가 다른 실행 종료와 함께 내려가 연결 오류가 발생했다. 단일 서버 소유로 전체 검사를 다시 실행해 해결했다. 포커스 검사 두 건은 오류 안내의 비동기 포커스 이동 완료를 기다리지 않던 테스트 경합으로, 실제 키보드 포커스와 outline 확인을 유지하면서 대기 순서를 수정했다.
