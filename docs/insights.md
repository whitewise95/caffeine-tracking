# 카페인 리포트

`/insights`와 하단 리포트 메뉴에서 현재 기록을 바탕으로 예측·기간별 섭취·패턴을 읽는다. 별도의 저장 데이터나 차트 라이브러리를 추가하지 않는다. 어두운 테마 토큰을 사용하고, hover 효과 없이 터치와 키보드로 그래프를 선택한다. 예측 곡선과 섭취 그래프는 하단 슬라이더 없이 그래프 자체를 탭해 선택하며, 방향키·Home·End로도 선택할 수 있다. 예측 곡선은 탭으로 5분 간격의 시각을 고른 뒤, 시각 옆의 좌우 버튼이나 방향키로 1분씩 조정한다. 선택 범위는 현재부터 24시간 뒤까지이며, 선택한 시각은 현재값 갱신에도 유지된다.

섭취 막대그래프는 CSS로 구현한다. 막대 폭을 최대 22px로 제한하고, 최대 기록량보다 여유 있는 mg 축과 옅은 가로 눈금을 표시한다. 하루 평균은 그래프 위에 숫자로 표시하고 점선만 그래프 내부에 둔다. 선택한 칸은 핑크와 커서로 구분하며, 전체 칸을 탭할 수 있다. 막대가 없는 0mg 구간을 선택했을 때만 옅은 배경 하이라이트를 표시한다. 한 번에 최대 7칸을 보여주며 각 칸의 시간·날짜를 표시한다. 오늘은 현재 시간과 앞뒤 3시간을 처음 보여주고 현재 시간을 선택한다. 이번 달은 오늘 날짜를 선택하고 오늘을 포함한 마지막 7일을 보여준다. 양끝에서는 0–23시 또는 저장 기간 안으로 제한한다. 7칸보다 긴 그래프는 기본 터치 스크롤이나 마우스 드래그로 좌우 구간을 볼 수 있고, 이전·다음 구간 버튼도 제공한다. 구간 이동은 선택을 바꾸지 않으며 탭·방향키·Home·End로 선택하면 해당 칸을 볼 수 있도록 스크롤한다. mg 축은 고정하며 화면 전체에 가로 넘침을 만들지 않는다.

화면은 세 영역으로 나눈다. 상단에는 기간 선택과 무관한 현재·미래 추정량을 둔다. 가운데 ‘기간별 기록’ 영역에는 오늘·7일·이번 달 버튼과 선택 기간의 섭취 그래프·패턴만 둔다. 별도의 기간 비교 카드는 표시하지 않는다. 마지막에는 기간 선택과 무관한 월간 요약·기록 달력을 별도 구분선 아래에 둔다. 월간 요약의 ‘월간 그래프 보기’는 이번 달을 선택하고 가운데 기간 영역으로 이동한다.

섭취 그래프 아래에는 선택 구간의 합계와 잔 수, ‘이날 기록 보기’ 버튼을 둔다. 음료별 배지는 표시하지 않으며, 버튼은 그래프에서 선택한 날짜의 기존 기록 화면으로 이동한다. 오늘 그래프에서는 어느 시간을 선택해도 오늘 기록을 연다.

예측 시각의 좌우 버튼은 짧게 누르면 1분씩 바뀌고, 0.4초 이상 누르면 반복 조정을 시작한다. 처음에는 천천히 반복하며 누른 시간에 따라 간격을 줄인다. 손을 떼거나 버튼 밖으로 움직이거나 터치가 취소되면 즉시 멈추고, 해제 시 추가 1분을 더하지 않는다. 선택 범위의 양끝, 앱 백그라운드 전환과 화면 이동에서도 반복을 중단한다. 카드 하단의 조작 안내 문구는 표시하지 않으며 키보드·스크린 리더 안내만 그래프에 연결한다.

## 계산 기준

- 오늘은 현지 자정부터 현재까지, 7일은 오늘을 포함한 최근 7개 달력 날짜, 이번 달은 1일부터 현재까지다. 미래·잘못된 시각/섭취량 기록은 제외한다.
- 섭취량과 잔 수는 기록의 종료 시각에 해당하는 날짜로 모은다. 천천히 마신 음료도 기존 기록 화면과 같은 기준이다.
- 평균은 선택한 기간의 달력 날짜 수로 나눈다. 미기록 날짜도 분모에 포함하되 실제 무섭취일로 부르지 않는다. 오늘은 진행 중이라는 안내를 제공한다.
- 오늘은 어제, 7일은 이전 7일, 월간은 지난달의 같은 날짜 범위와 비교한다. 짧은 달은 마지막 날짜로 제한한다. 지난 기간 평균이 0이거나 비교할 기록이 없으면 증감률을 표시하지 않는다.
- 밤 10시 추정치는 기존 흡수·감소 모델로 계산한다. 이전 날짜의 잔존량을 포함하며, 종료가 늦은 분할 섭취도 해당 시각까지 흡수된 부분만 모델이 반영한다. 오늘의 밤 10시는 미래 예측일 수 있다.
- 현재부터의 예측은 현재까지 완료된 기록만 사용한다. 24시간 곡선은 약 15분 간격으로 그리되, 선택 시각의 예상량은 해당 시각으로 직접 계산한다. 오늘의 최고점은 자정부터 현재까지 5분 간격으로 계산한다. 최신 현재값도 최고점 후보에 포함한다.
- 현재량의 절반 시각은 앞으로 72시간 동안 15분 간격으로 찾는 근사치다. 흡수 중이라면 설정 반감기만큼 시간을 더한 값과 다를 수 있다. 현재 추정량 1mg 미만이면 표시하지 않는다.
- 평균 마지막 섭취 시각은 기록 있는 날만 사용한 원형 평균이다. 자정 주변 시각을 정오로 잘못 평균하지 않는다.
- 패턴은 저장된 음료 수의 2시간 구간, 기간 평균 변화, 오후 6시 이후 종료한 기록이 있는 날짜 수에서 최대 3문장을 만든다. AI나 가상 기록을 사용하지 않는다.

## 해석 경계

‘예정 취침 시각’을 누르면 앱 안의 바텀시트에서 오전·오후, 시, 분을 세 개의 휠로 선택한다. 기존 섭취 시각 선택기를 재사용하며 스크롤·숫자 탭·키보드를 지원한다. 완료를 눌렀을 때만 Repository에 저장하고, 성공하면 시트를 닫아 설정과 홈에 반영한다. 저장 실패는 시트 안에 알리고 선택한 초안은 유지해 재시도할 수 있다. 취소·닫기·Escape·브라우저/Android 뒤로가기는 초안을 버리고 설정의 펼쳐진 아코디언으로 돌아간다. 시트는 기존 라우터 overlay로 관리해 네이티브 뒤로가기와 iOS swipe-back 제어를 공유한다.

반감기는 앱의 계산 가정이며 개인별 측정·추론 값이 아니다. 카페인량만으로 수면 영향 등급, 안전한 취침 시각, 실제 집중 상태를 판정하지 않는다. 취침 예정 시각의 추정 잔존량을 보여준다. 예정 시각은 공통 설정으로 저장하며 홈 요약의 예상 잔존량에도 적용한다. 처음에는 23:00을 사용하고, 선택 시각이 이미 지났으면 다음 날의 같은 시각으로 계산한다. 화면 이동·새로고침 후에도 유지하며 저장에 실패하면 기존 시각을 유지한다. 설정의 ‘잠들 무렵에는’ 아코디언은 기본으로 접혀 있으며, 펼치면 예정 취침 시각·추정 잔존량·안내를 보여준다. 리포트에는 이 카드를 표시하지 않는다. 안내 문구는 미기록 상태를 따로 두고, 화면에 반올림해 표시한 잔존량에 따라 0–24mg(VERY_LOW), 25–49mg(LOW), 50–99mg(MODERATE), 100–149mg(HIGH), 150mg 이상(VERY_HIGH)으로 나눈다. 이는 앱에서 정한 잔존량 안내 구간이며, 의학적으로 검증된 수면 영향 등급이나 발생 확률이 아니다. 적은 추정량을 수면 영향 없음으로 표현하거나 높은 추정량을 높은 발생 확률로 단정하지 않는다. 양이 남는 경우 잠들기와 깊은 수면에 미칠 수 있는 일반적인 영향을 설명하고, 마지막 섭취 종료 후 취침까지 간격을 표시한다. 취침 시각을 바꾸면 문구도 다시 계산한다.

수면 카드에는 연구 설명을 펼치는 영역을 두지 않는다. 문구의 근거는 [EFSA 카페인 설명](https://www.efsa.europa.eu/en/topics/topic/caffeine)과 [카페인 섭취량·시각과 수면 연구](https://academic.oup.com/sleep/article/48/4/zsae230/7815486)를 참고한다. 이 연구의 **섭취량**을 앱의 **잔존 추정량** 기준값으로 사용하지 않는다.

월간 달력의 색은 하루에 기록한 음료 개수의 고정 5단계(0개·1개·2개·3개·4개 이상)다. 카페인 mg나 이번 달 최대 기록량에 따라 변하지 않는다. 프라이머리 핑크의 진하기로 구분하며, 범례에 각 기록 수를 표시한다. 건강 등급이나 보상 점수가 아니다. 기록 유무와 관계없이 오늘이 기본 선택되며, 선택한 날짜는 프라이머리 핑크 테두리와 선택 상태로 구분한다. 미래 날짜는 비활성화하고, 미기록 날짜는 ‘기록 없음’으로 읽는다. 날짜를 선택한 뒤 기록 보기로 해당 날짜의 기존 기록 화면을 연다.

## 검증

`report.test.ts`는 기간 정렬·분모·잘못된/미래 기록 제외·이전 날짜의 잔존량·흡수 곡선·자정·월 길이·근사 최고점/절반 시각을 검증한다. `insights.spec.ts`는 375/390px, 어두운 테마에서 직접 라우팅·빈 기록·예측·그래프 선택·기간 전환·취침 시각·날짜별 기록 이동·글자 확대·하단 메뉴 여백을 검증한다.

`bedtime-forecast.spec.ts`는 브라우저·Toss 저장소에서 홈과 설정의 취침 시각 연동, 다음 날 시각 계산, 새로고침 후 유지, 저장 실패와 재시도를 확인한다.

`insights-scroll.spec.ts`는 현재 시간 기준 7칸, 월간 7개 날짜, 실제 터치 스와이프·마우스 드래그와 탭 선택의 분리, 구간 버튼·키보드 이동, 자정·월초 경계와 글자 확대를 검증한다.
