# 답변 기반 계산 반감기 보정

> 보관 문서: 2026-10-04 사용자 요청에 따라 관련 UI·설문·보정 로직을 제거했습니다. 현재 앱은 기본 반감기 4시간 30분을 사용합니다(2026-10-05 변경). 아래의 5시간 기준과 검증 결과는 당시 설계 또는 추후 검토 자료로 보존합니다.


2026-10-04 · `daily-feeling-half-life-v1`

## 목적과 의미

사용자가 매일 남기는 `오래 갔어요 / 비슷했어요 / 빨리 줄었어요`를 앱의 **잔존 카페인 계산에 사용하는 반감기**에 반영한다. 체감 지속 시간 숫자만 보정하던 이전 동작에서 변경했다. 이것은 자기보고를 계산 모델에 연결하는 실험적 제품 규칙이며, 개인의 생리학적 반감기를 측정하거나 식별한 결과가 아니다.

주관적 반응과 제거 속도의 관련성을 보고한 작은 연구가 있지만([Levy 1983](https://pubmed.ncbi.nlm.nih.gov/6851408/)), 세 가지 일일 응답으로 개인 반감기를 추정하는 본 알고리즘을 검증하지 않았다. 주관적 반응과 생리 반응의 내성도 다를 수 있다([Sigmon 2009](https://pubmed.ncbi.nlm.nih.gov/19241060/)). 따라서 아래 조정 폭·범위는 논문에서 도출한 개인화 상수로 소개하지 않는다. 사용자별 잔존 mg 정확도 개선은 아직 확인되지 않았다.

## 적용 규칙

초기 H=5시간에서, 현재 섭취 원본·시간대·시각에 대해 유효한 일일 응답을 응답 시각과 id 순으로 한 번씩 재생한다.

```text
delta = 오래 갔어요: +0.25h / 비슷했어요: 0 / 빨리 줄었어요: −0.25h
H_next = clamp(H_current + delta, 3h, 8h)
ke = ln(2) / H
```

범위는 각 응답마다 적용한다. 따라서 하한에서 반대 답변을 하면 즉시 3시간15분이 되고, 과거에 하한을 넘어 누적된 숨은 값은 없다. 5시간 기준·15분 폭·3~8시간 범위는 동작의 크기를 제한하기 위한 제품 운영값이다. 생물학적 가능 범위 또는 안전 경계가 아니다.

`getAdaptiveHalfLifeHours`는 `reconcilePersonalization`으로 유효성을 검토한 상태에서 `responseKind: daily-feeling`이며 해당 update가 `learned`이고 가중치가 양수인 응답만 반영한다. 과거 예측과 비교한 legacy 응답, 시간 구간 응답, 모르겠음, 건너뛰기, 교란이 있거나 원본이 바뀐 응답은 제외한다. 기존 체감 지속 시간 보정 θ를 반감기로 변환하지 않는다.

## 화면 및 PK 연결

- `useCaffeine`은 원본 저장 상태와 별도로 `halfLifeHours`를 도출한다.
- 홈 mg·몸 액체 높이·음료별 잔존량·밤 예측·설정의 시간/분·수식의 ke가 모두 이 값을 사용한다.
- 흡수 속도 ka=4.54/h와 F=1 가정, 단일 시각 및 균일 구간 섭취 계산은 유지한다. [경구 모델](./oral-caffeine-model.md).
- 답변 저장 성공 후에만 현재 추정치를 갱신한다. 저장 실패 시 값이 바뀌지 않는다.
- 반감기가 바뀌면 과거 시각의 원본 섭취 기록부터 현재값을 **재추정**한다. 답변 순간에 몸속 카페인이 실제로 갑자기 늘거나 줄어든다는 의미가 아니다. 과거에 저장한 체감 예측 스냅샷은 수정하지 않는다.
- 수동 반감기 입력은 제공하지 않는다. 설정에는 `계산에 쓰는 추정 반감기`와 측정값이 아니라는 짧은 설명을 표시한다. 상세 계산 설명에서 조정 폭·범위·미검증 상태를 확인할 수 있다.

## 보관·재계산·보류

기존 스키마 v2와 저장 기준 `settings.halfLifeHours=5`를 유지한다. 실제 적용값은 원본 답변에서 도출하며 별도의 가변 캐시를 저장하지 않는다. 새로고침·다시 열기로 중복 가산하지 않고, 기존 유효한 일일 답변도 새 계산에 반영된다. 기록/답변 수정·삭제 뒤에는 유효한 응답을 다시 재생한다. 시작 시각 `startedAt`을 고쳐도 원본 변경으로 처리한다.

설정의 `다음 날 체감 질문 받기`를 꺼도 기존 답변은 계산에 반영된다. 응답을 모두 삭제하면 기본 5시간으로 돌아가며 음료 기록은 유지된다. 전체 초기화는 원래대로 모든 앱 데이터를 제거한다.

기존 자료 보류 정책을 따른다: 최근 유효 응답 이후 14일을 넘기거나 현재 시간대와 최근 응답 시간대가 다르면 기본 5시간을 사용하고 설정에 이유를 표시한다. 14일을 넘긴 공백 후 새 응답은 새로운 보정 구간을 시작한다. 이 기간 역시 생물학적 변화에 근거한 상수가 아닌 운영 정책이다.

## 검증 범위

자동 테스트는 조정 방향·한계·반대 방향 복귀·답변 편집/삭제·원본 변경·보류·재접속·저장 실패와 모든 PK 화면에 같은 값이 전달되는지를 검증한다. 수치 테스트와 브라우저 흐름 검증은 실제 개인별 약동학 정확도 검증을 대신하지 않는다.
