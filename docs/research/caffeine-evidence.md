# 카페인 추정·체감 개인화의 문헌 근거

검토일: 2026-10-04 (프로젝트 작업일, Asia/Seoul). 상태: 구현 설계를 위한 제한적 문헌 검토. 앱의 예측 성능 또는 임상 유효성 검증 결과가 아니다.

앱 적용 기준 갱신: 2026-10-05. 고정 반감기를 4시간 30분으로 변경했으며 아래 논문의 보고값은 그대로 보존한다.

## 검색과 선택 방법

사용자가 지정한 다섯 논문을 출발점으로 PubMed, PMC 및 학술지 원문을 웹 검색했다. 흡수·반복 투여·내성·금단을 다루는 인간 대상 원 연구 세 편을 추가했다. 이후 섭취별 흡수·제거 모델을 검토하며 Terziivanov 2003, Seng 2009, Ramakrishnan 2013·2014와 EFSA 설명자료를 추가 확인했다. 이 문서는 모든 연구를 수집한 체계적 문헌고찰이나 메타분석이 아니다. 검색일 이후 문헌과 검색에서 누락된 연구가 있을 수 있다.

PMC 직접 열기는 일부 CAPTCHA를 반환했다. 해당 논문의 검색 도구에 노출된 PMC 본문 및 학술지 원문을 확인했다. 아래 접근 수준을 구분했으며, 보충자료·원시 데이터까지 모두 재분석하지 않았다. 표의 `미확인`은 0 또는 분산 없음이 아니다.

## 근거에서 도출한 구현 결정

다음은 위 연구와 현재 수집 자료를 바탕으로 한 **설계 판단**이며, 논문에서 직접 검증한 앱 알고리즘이 아니다.

### 체감 신호와 실제 반감기 측정을 구분한다

현재 입력은 음료·섭취량·섭취 시각과 선택적 시작·종료 시각이다. 기본 반감기 4시간 30분과 흡수 속도 4.54/h를 사용한다. 체감 설문과 답변 기반 보정 로직은 사용자 요청에 따라 제거했으며, 수동 반감기 설정 UI도 제공하지 않는다. 이전 체감 데이터는 호환성 보관 정보로만 남겨 계산에 사용하지 않는다.

홈 mg와 인체 액체 높이는 1구획 PK 근사이며 흡수 전 양은 제외한다. 개인 반감기를 측정한 값이 아니다. 아래 체감 모델 검토와 검증 계획은 향후 기능 검토 자료다.

| 별도 체감 시간 보정 | 이전 예측 스냅샷, 독립적인 관측 시간 구간 또는 순서형 응답 | 자기보고 결과에 관한 향후 예측의 개선 여부 | 구현에서 제거. 추후 검토 대상으로 보관 |

현재 모델 `oral-uniform-intake-v2`는 기본적으로 `A(t)=dose × ka/(ka−ke) × (exp(−ke×t)−exp(−ka×t))`의 섭취별 합이다. `ka=4.54/h`, `ke=ln(2)/H /h`, `F=1` 가정을 사용한다. H는 기본 4.5h(4시간 30분)로 고정한다. 선택적으로 시작·종료 시각을 입력하면 일정한 경구 입력률 `dose/기간`을 위 식에 적분한다. 이는 선형 모델의 수학적 확장이며, 논문이 검증한 개인별 섭취 패턴이 아니다. 전날 기록을 포함하고 아직 마시지 않은 분량은 현재량과 예측에서 제외한다. 흡수 전 양은 별도로 계산하여 음료 목록의 `흡수 중` 표시에 사용한다. 단일 시각 섭취에서는 `A(0)=0`, `G(0)=dose`이며 섭취 초기에는 A가 늘 수 있다. 농도가 아닌 mg 추정이므로 분포용적은 도입하지 않는다.

현재 4시간 30분은 앱에서 정한 고정 계산 기준이다. Terziivanov 2003의 `ke=0.139/h`를 환산한 반감기는 약 4.99h이며, 앱의 4.5h를 직접 도출한 근거는 아니다. 앱의 제거 속도는 `ke=ln(2)/4.5 ≈ 0.154/h`로 계산한다. [EFSA 공식 설명자료](https://www.efsa.europa.eu/sites/default/files/corporate_publications/files/efsaexplainscaffeine150527.pdf)는 건강한 성인 평균 약 4h, 범위 2–8h를 설명한다. 어느 단일 값도 모든 사용자에게 정확하지 않다. EFSA의 평균을 개인값으로 적용하거나 현재 4.5h를 개인 측정치로 해석하지 않는다.

흡수 모델은 초기 시간 경과를 표현하기 위한 선택이다. 단일 ka를 모든 음료에 적용하고, 선택적 섭취 구간도 일정한 속도로 마셨다고 가정하므로 실제 흡수의 개인차·제형·음식·모금별 패턴의 차이는 남는다. 더 복잡한 모델을 쓴다고 앱의 예측 성능이 검증되는 것은 아니다. `ka=ke` 극한과 근접 상수에서의 수치 안정성, 질량 보존, 구간 경계의 연속성, 섭취별 합산을 자동 테스트한다. [모델 정의·예시·한계](./oral-caffeine-model.md)를 참고한다.

### 문헌으로 정해지지 않은 운영 가정

다음은 코드·설계에 명시하고 실제 자료로 조정해야 한다: 체감 기준 시간대, mg 입력 특성의 임계값을 사용할 경우 그 값, 학습률, 정규화 강도, 허용 보정 범위, 한 번의 최대 변경량, 응답 수 기준, 회상 기간, 야간 체크인 지연, 교란 가중치, 성능 악화 시 복귀 조건. 어느 값도 '논문으로 확인된 개인화 상수'로 표시하지 않는다. 특정 mg 아래를 체감 소멸·수면 가능·완전 제거의 생리학적 경계로 설명하지 않는다. 이전 보정 설계의 ±15분·3~8시간 한계도 검증된 생물학적 상수가 아니다. 체감 응답을 반영했다는 사실은 예측 정확도가 향상됐다는 증거가 아니다.

우선 보정의 방향과 안정성만 검증할 수 있다. '모르겠음', 미응답, 건너뛰기에는 학습 신호를 부여하지 않는다. 비교 응답은 실제로 사전에 보여준 예측과 연결한다. 아직 종료되지 않은 야간 체감 구간은 다음날 자정이 되었다는 이유만으로 평가하지 않는다. 누락 섭취·추가 섭취·불명확한 체감·교란이 있으면 보류한다.

## 충돌·불확실성과 후속 검증

용량별 비선형 PK 결과가 있어 선형 흡수·제거 합산은 근사다. 흡수 연구의 빠른 흡수 결과는 즉시 흡수를 증명하지 않는다. 수면 연구의 유의·비유의 차이는 서로 다른 용량·시각·측정·표본에 관한 결과이므로 하나의 보편적인 종료 시각으로 합치지 않는다. 여러 연구에서 평균 효과가 확인되어도 개인의 정확한 반감기를 알 수 있다는 뜻은 아니다.

음료의 `sample/official/custom` 출처는 보존한다. 출처 유형만으로 함량 오차 분포를 정할 수 없고, 미기록 섭취는 기록값만으로 복원할 수 없다. 임신·복약·흡연 등에 일괄 배율을 적용하지 않는다. 민감한 입력을 추가하려면 구체적인 예측 이점과 개인정보 필요성을 따로 검토해야 한다.

실제 체감 예측 성능은 동의한 사용자 자료에서 시간순으로 **예측 → 관측 → 평가 → 학습** 순서로 검증한다. 이전 예측을 업데이트된 모델로 다시 계산해서 평가하지 않는다. 고정 기준 모델과 개인화 후보를 같은 관측으로 비교한다. 독립적인 시간 구간에는 구간 오차를, 순서형 응답에는 적합한 우도·로그 손실을 사용하고 관측 종류를 섞어 정확도 한 개로 표현하지 않는다. 앵커링·응답 누락·사용자별 편차도 기록한다. 개선되지 않으면 보정을 보류하거나 기준 모델로 복귀한다.

임계값·보정 폭·정규화 강도를 바꾼 민감도 분석과 합성 데이터 실험은 구현의 안정성을 확인하는 수단이다. 실제 사용자 예측 성능, 잔존 mg 정확도, 생리학적 반감기 검증을 대체하지 않는다. 이 문서의 어느 연구도 본 앱의 다음날 체크인·온라인 학습 알고리즘을 임상적으로 검증하지 않았다.
