## 변경 결과

일일 설문이 기존 체감 시간 보정값만 저장하던 문제를 수정했다. 유효한 세 가지 답변을 시간순으로 재생하여 기본5시간에서 +15분/유지/−15분, 3~8시간 범위의 **계산 반감기**를 도출한다. 동일한 값이 홈 총량, 몸 시각화, 음료별 잔존량, 밤 예측, 설정 시간/분 및 계산식의 ke에 전달된다.

저장 상태의 기본값5시간과 원본 응답을 유지하고 파생값을 별도로 반환한다. 재접속·주기 갱신으로 중복 가산하지 않으며 답변 수정/삭제·섭취 기간 변경 후 재계산한다. 질문을 꺼도 기존 보정은 반영되고, 응답을 모두 지우면 기본값으로 돌아간다. 기존의14일 공백·시간대 변경 보류 시에는5시간을 사용하고 설정에 이유를 안내한다. [정책과 과학적 한계](./research/adaptive-half-life.md).

새 도메인 테스트18개는 실제 답변 제출·편집·삭제·재검증 함수를 사용한다. 조정 방향, 비슷 응답 유지, 상·하한, 한계 도달 뒤 반대 방향 복귀, 순서 재생, 재접속과 중복 답변, 원본 startedAt 변경, 교란·미래·삭제된 원본 제외, 질문 끄기, 과거 예측 비교 응답 제외 및 보류 정책을 검증했다.

브라우저의 기본3방향 테스트는 홈154mg·밤39mg 조건에서 오래 답변 후162mg·43mg, 비슷 답변 후154mg·39mg, 빨리 답변 후146mg·34mg을 확인했다. 몸 액체 위치, 음료별 수치, 리로드 및 설정5시간15분/5시간0분/4시간45분도 확인했다. 비교 시각을 고정해 시간 경과가 답변 효과 비교에 섞이지 않게 했다.

기존 응답을 처음 불러올 때 같은 반감기가 모든 화면에 연결되는지, 저장 실패 시 값이 그대로이고 성공한 재시도 뒤에만 바뀌는지 검증했다. 14일 보류 시 기본값 안내와 응답 보존도 확인했다. 새 응답을 저장하는 테스트는 격리된 Playwright 저장소에서만 실행했다.

`localhost:5174/settings`에서 새 반감기 표시와 측정값이 아니라는 안내, 계산식이 보이는 것을 직접 확인했다. 사용자 원본 응답·섭취 기록을 테스트 목적으로 바꾸지 않았다. iOS/Android Toss 실기기 검증과 임상 성능 검증은 수행하지 않았다.
