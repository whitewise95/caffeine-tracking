## 포함한 변경

- 음료 편집 미리보기, 완료 시 일괄 저장, 초기화·닫기·뒤로가기 취소.
- 편집 상단의 카테고리 추가·초기화, 짧은 배지 흔들림, 배치 변경 버튼 제거.
- 드래그 입력·미리보기 갱신 최적화와 빠른 드롭 처리.
- 기록·수정의 시작/종료 날짜·시각과 카페인 조절 UI 통일.
- 오늘을 기본 선택하는 기록 화면, 리포트와 같은 기록 수별 달력 색상.
- 설정 정리와 지식 화면의 반감기·계산 설명.

AI 채팅과 Supabase 연동은 포함하지 않는다.

## 검증과 재빌드

업로드 전 ESLint, 단위 테스트 459개, TypeScript·Vite·AIT 빌드를 통과했다. 관련 모바일 브라우저 테스트는 각 변경 작업에서 실행했으며, 실제 토스 기기에서의 사용자 테스트 결과와 구분한다.

```bash
npm run lint
npm test
npm run build:toss
```

새로 빌드하면 deploymentId와 번들 해시가 바뀔 수 있다. 위 값은 이 테스트 업로드에 사용한 파일의 값이다. 테스트 절차는 [앱인토스 공식 가이드](https://developers-apps-in-toss.toss.im/guide/operation/toss)를 따른다.
