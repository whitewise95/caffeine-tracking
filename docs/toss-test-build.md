## 포함한 변경

- 모자·안경·상의·하의·신발·소품을 각각 50개로 확장한 300개 아바타 아이템.
- 젤리 몸의 곡면을 감싸는 상·하의 실루엣, 입체 명암과 앞뒤 레이어, 컵을 든 팔의 소매 연결 개선.
- 홈에서 저장된 코디를 잠시 숨겼다가 그대로 복원하는 `겉멋 끄기`.
- 꾸미기에서 선택된 아이템을 다시 누르면 해당 슬롯만 벗는 토글 동작.
- 오늘 기록인 마지막 섭취는 날짜를 생략하고, 이전 날짜일 때만 날짜 표시.
- 시간 휠에서 손가락이 조금 흔들린 탭도 숫자 선택으로 안정적으로 인식.
- 기존 카페인 계산, 액체 높이, 표정, 기록과 저장 데이터 호환성 유지.

## 검증과 재빌드

업로드 전 ESLint, 단위 테스트 490개, TypeScript·Vite·AIT 빌드를 통과했다. 375px·390px에서 아바타 꾸미기 E2E 44개와 시간 선택기 E2E 26개가 통과했다. 전체 브라우저 테스트를 8개 워커로 실행했을 때 502개 중 495개가 통과했고, 부하에 민감해 실패한 5종 7건은 단일 워커 재검증에서 두 뷰포트 모두 10/10 통과했다. 실제 토스 기기 테스트 결과와는 구분한다.

```bash
npm run lint
npm test
npm run build:toss
```

새로 빌드하면 deploymentId와 번들 해시가 바뀔 수 있다. 위 값은 이 테스트 업로드에 사용한 파일의 값이다. 테스트 절차는 [앱인토스 공식 가이드](https://developers-apps-in-toss.toss.im/guide/operation/toss)를 따른다.
