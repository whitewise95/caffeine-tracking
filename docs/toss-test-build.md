## 포함한 변경

- 모자·안경·상의·하의·신발·소품을 각각 50개로 확장한 300개 아바타 아이템.
- 젤리 몸의 곡면을 감싸는 상·하의 실루엣, 입체 명암과 앞뒤 레이어, 컵을 든 팔의 소매 연결 개선.
- 홈에서 저장된 코디를 잠시 숨겼다가 그대로 복원하는 `겉멋 끄기`.
- 꾸미기에서 선택된 아이템을 다시 누르면 해당 슬롯만 벗는 토글 동작.
- 오늘 기록인 마지막 섭취는 날짜를 생략하고, 이전 날짜일 때만 날짜 표시.
- 시간 휠의 숫자 탭과 키보드 조작, 안내 문구를 제거하고 터치·마우스 세로 드래그로만 값을 변경하도록 단순화.
- 시간 휠을 드래그해 선택값이 한 칸 바뀔 때마다 Toss의 약한 `tickWeak` 햅틱을 제공. 초기 표시와 코드 동기화에는 진동하지 않고, 햅틱 실패 시에도 시간 선택은 계속 동작.
- 비상호작용 요소로 바꾼 시간 휠의 오전·오후와 숫자 레이블을 각 선택 칸의 가로·세로 중앙에 명시적으로 정렬.
- 꾸미기 적용 버튼에 `AD` 표기를 추가하고, 저장 성공 후 전면 광고 그룹 `ait.v2.live.cf69107c15014790`을 노출. 광고 미지원·미로딩·표시 실패 시에는 저장과 화면 이동을 그대로 진행.
- 기존 카페인 계산, 액체 높이, 표정, 기록과 저장 데이터 호환성 유지.

## 검증과 재빌드

업로드 전 ESLint, 단위 테스트 494개, TypeScript·Vite·AIT 빌드를 통과했다. 375px·390px에서 시간 선택기 E2E 28개가 모두 통과했다. Toss 호스트 통합 테스트로 각 드래그 선택값 변경의 햅틱 호출과 코드 동기화 시 무진동을 확인했고, 렌더링 테스트로 세 휠 레이블의 시각적 중앙 정렬을 검증했다. 프로덕션 번들에는 라이브 광고 그룹 ID만 포함되고 개발·자동 테스트에서는 공식 전면 광고 테스트 ID를 사용한다. 실제 진동의 세기는 기기 테스트에서 확인해야 한다.

```bash
npm run lint
npm test
npm run build:toss
```

새로 빌드하면 deploymentId와 번들 해시가 바뀔 수 있다. 위 값은 이 테스트 업로드에 사용한 파일의 값이다. 테스트 절차는 [앱인토스 공식 가이드](https://developers-apps-in-toss.toss.im/guide/operation/toss)를 따른다.
