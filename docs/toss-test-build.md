## 검증과 재빌드

업로드 전 ESLint, 단위 테스트 492개, TypeScript·Vite·AIT 빌드를 통과했다. 375px·390px에서 아바타 꾸미기 E2E 44개와 시간 선택기 E2E 26개가 통과했다. 프로덕션 번들에는 라이브 광고 그룹 ID만 포함되고 개발·자동 테스트에서는 공식 전면 광고 테스트 ID를 사용한다. 실제 토스 기기 테스트 결과와는 구분한다.

```bash
npm run lint
npm test
npm run build:toss
```

새로 빌드하면 deploymentId와 번들 해시가 바뀔 수 있다. 위 값은 이 테스트 업로드에 사용한 파일의 값이다. 테스트 절차는 [앱인토스 공식 가이드](https://developers-apps-in-toss.toss.im/guide/operation/toss)를 따른다.
