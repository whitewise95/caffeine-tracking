## 적용 내용

- 기본 기록은 현재 시각의 단일 섭취를 유지한다.
- `천천히 마셨어요` 선택 시 시작·마지막 날짜와 시각을 입력한다. 두 시각 사이에 일정한 속도로 마셨다는 가정을 안내한다.
- 경구 입력 → 흡수 전 구획 → 흡수된 잔존량 → 제거를 계산한다. 고정 제거 반감기 5시간, ka=4.54/h를 유지한다.
- 기존 저장 v2에 선택적 `startedAt`을 추가한다. `consumedAt`은 마지막 시각이며 기존 단일 기록은 변형하지 않는다.
- 홈·음료별 목록·밤 예측에 같은 PK 엔진을 적용한다. 날짜별 총량·잔 수는 마지막 시각의 날짜로 모은다.
- 기록 편집에서 구간을 변경·제거할 수 있다. 시각을 변경하지 않고 mg만 수정하면 기존 초 단위 timestamp도 보존한다.
- 체감 스냅샷에 선택적 시작 시각을 포함해 기간 수정 시 이전 자료에 의존한 보정을 제외한다. 체감 응답은 PK 반감기를 바꾸지 않는다.

새 E2E 14개는 기본 기록 호환, 구간 입력·저장·재접속, 수정·구간 제거, 자정 넘김과 종료 날짜 분류, 빈 값·역전·미래 종료 거부, 초 단위 기록 보존, 두 테마의 200% 글꼴에서 입력 및 저장 접근을 확인한다. 기존 기록·설문·저장 오류·뒤로가기·수식·시각화 테스트도 함께 통과했다. 테스트 데이터는 격리된 Playwright 브라우저에서만 생성했다.

실행 중인 `localhost:5174`에서도 음료 선택 후 구간 입력과 설명·저장 버튼이 표시되는 것을 확인했다. 실제 사용자 기록으로 테스트 음료를 저장하지 않았다. iOS·Android Toss 실기기의 네이티브 날짜 선택기는 이번 검증에 포함하지 않았다.
