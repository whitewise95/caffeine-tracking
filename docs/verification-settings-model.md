# 설정 반감기 표시와 계산식 정리

2026-10-04. 현재 계산에 전달되는 `state.settings.halfLifeHours`를 시간·분으로 표시한다. 현재 저장 모델은 5시간 고정이므로 5시간 0분을 표시하며 직접 조절하는 입력은 없다. 이전 수동 설정에 대한 긴 안내는 화면에서 제거하고 저장 이력은 보존했다.

계산식은 `섭취량 × 0.5^(경과 시간 / 반감기)`로 유지한다. 지수는 밑보다 위에 배치하고 분자는 경과 시간, 분모는 반감기로 분리한다. 단위는 시간으로 명시하며 스크린리더용 설명을 제공한다. 글자 확대 때 식의 묶음 사이에서 줄바꿈을 허용한다.

체감 보정은 잔존량 계산과 별도라는 기존 구현을 유지했다. 화면에는 체감 보정값이 답변에 따라 조정된다는 안내를 제공한다. 사용자가 요청한 반감기 자동조정 문구는 기존 개발 프롬프트의 PK/PD 분리와 충돌할 수 있어, 실제 잔존량 계산까지 바꾸려는 것인지 확인 질문을 보냈다. 이 검증 시점에는 답변이 없으므로 반감기 자동조정은 연결하지 않았다.

린트, TypeScript/Vite 빌드 통과. 단위 테스트 99개 및 모바일 브라우저 전체 테스트 72개 통과. 375px·390px, 두 테마, 200% 글자 확대, 지수와 분수의 실제 배치, 수동 입력 부재를 검증했다. 실제 토스 기기 검증은 포함하지 않는다.
