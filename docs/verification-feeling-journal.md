# 체감 기록 화면 전환 검증

> 보관 문서: 아래는 2026-10-04 당시 구현·검증 기록입니다. 당시의 5시간 기준과 실행 결과는 그대로 보존합니다. 현재 앱은 4시간 30분을 고정 기준으로 사용하며 설문·응답 기반 보정은 제공하지 않습니다. 최신 동작은 [README](../README.md)와 [현재 모델](research/oral-caffeine-model.md)을 참고하세요.

> 이후 사용자 요청으로 최근 7일 체감 요약과 안내 문구를 제거했다. 아래 내용은 제거 전 검증 기록이다. 현재 기록 화면은 날짜별 섭취 이력만 제공하며, 설문과 설정의 응답 관리는 유지한다.

제거 후 검증: `npm run lint`, `npm run build` 통과. `npm test` 4개 파일 96개 통과. `npm run test:e2e -- tests/history.spec.ts tests/personalization.spec.ts` 모바일 375px / 390px 50개 통과. 요약 전용 컴포넌트·집계 함수·스타일·테스트를 정리했으며 저장 데이터와 설문 동작은 유지했다.

2026-10-04. 체감 예측의 홈 노출을 제거하고 실제 자기보고 기록을 조회하는 UX로 전환했다.

- 홈에서 체감 지속 시간 구간·예측 보기 버튼을 제거했다. 기존 저장 예측도 자동 표시하지 않고, 과거 응답 편집을 위해 데이터는 보존한다.
- 설문 이유는 `나의 카페인 체감 패턴을 알아보기 위해 물어봐요.`로 변경했다. 전날 양수 섭취 + 미응답 팝업, 세 답변, 저장·닫기 동작은 유지했다.
- 기록 화면의 최근 7일 요약은 오늘을 포함한 7개 현지 날짜 기준이다. 새로운 `daily-feeling` 응답만 세며 이전 예측 비교·모르겠음·건너뛰기를 섞지 않는다. 날짜마다 한 번 세고 미응답을 비슷함으로 채우지 않는다. 미래 응답·수정은 현재 요약에 포함하지 않는다.
- 요약은 달력에서 선택한 날짜와 별개인 최근 7일 통계다. 실제 응답이 하나 이상 있을 때 표시하고, 범위 안내와 응답 일수를 제공한다. 응답 수정·삭제에 따라 즉시 갱신한다.
- 설정은 `체감 기록`, `다음 날 체감 질문 받기`, 응답 수정·삭제로 정리했다. 학습 상태·성능 개선·시간 보정·새 예측을 위한 근거 노출은 제거했다.
- 기존 도메인 보정/예측 함수와 저장 데이터는 호환성을 위해 유지하며 새 UI에서 예측을 생성·노출·저장하지 않는다. 잔존 mg는 5시간 기본 반감기로 계속 계산한다.
