현재 카페인 추적 앱에 ‘젤리 캐릭터 꾸미기’ 기능을 추가해줘.

이 기능은 사용자가 홈의 젤리 캐릭터에 모자, 안경, 소품, 상의, 하의, 신발을 입혀 자신만의 아바타로 꾸미는 시스템이다.

새로운 캐릭터나 별도 게임을 만드는 것이 아니라, 현재 캐릭터의 형태와 유리 같은 질감, 카페인에 따라 변하는 액체와 표정을 유지하면서 꾸미기 기능을 확장하는 것이 목표다.

아래 기획을 기준으로 현재 프로젝트를 살펴보고, 기존 기술 환경과 구현 방식에 맞춰 개발해줘. 구체적인 파일 구성이나 컴포넌트 분리는 실제 코드를 확인한 뒤 적절하게 결정하면 된다.

기획 설명이나 화면 예시만 만드는 것이 아니라, 아이템 선택부터 실제 착용, 저장과 복원까지 사용할 수 있는 기능으로 구현해줘.


1. 서비스에서 이 기능이 맡는 역할

현재 캐릭터는 사용자의 추정 잔존 카페인을 보여주는 역할을 한다.
여기에 사용자가 직접 고른 옷과 소품을 더해 ‘내 캐릭터’라는 애착을 만들고 싶다.

다만 꾸미기 때문에 카페인 기록과 확인이라는 앱의 핵심 목적이 밀려나면 안 된다.
홈의 정보 구조와 기존 동작을 유지하고, 꾸미기는 사용자가 원할 때 진입하는 부가 기능으로 제공한다.

이번 MVP는 기능 범위를 작게 잡되, 아이템의 선택지는 충분히 제공한다.

포함할 기능:
- 부위별 아이템 탐색
- 실시간 착용 미리보기
- 부위별 착용과 해제
- 전체 착용 해제
- 적용하기
- 저장된 모습의 홈 반영과 재진입 시 복원

제외할 기능:
- 상점, 결제, 재화, 뽑기
- 출석, 미션, 보상, 아이템 해금
- 계정 간 동기화와 별도 서버 구축
- 사용자 이미지 업로드
- 아이템 위치·크기의 자유 편집
- 색상 편집기, 코디 저장 슬롯, 공유 기능

모든 기본 아이템은 처음부터 자유롭게 사용할 수 있게 한다.


2. 아이템 구성: 6개 부위, 각각 10종

모자, 안경, 소품, 상의, 하의, 신발을 각각 10종씩 제공한다.
총 60개의 실제 착용 가능한 아이템을 구현한다.

‘착용 안 함’은 별도의 선택 옵션이며 아이템 개수에 포함하지 않는다.
신발은 좌우 한 쌍을 하나의 아이템으로 취급한다.

단순히 같은 형태의 색만 바꿔 10종을 채우지 않는다.
실루엣, 형태, 디테일이 구분되는 디자인으로 구성한다.
썸네일이나 이름만 존재하고 실제 착용 그래픽이 없는 아이템은 허용하지 않는다.

기본 구성은 다음을 기준으로 한다.

[모자 10종]
비니, 베레모, 볼캡, 버킷햇, 페도라, 작은 왕관, 파티 고깔모자, 수면 모자, 선원 모자, 베이커 모자.

[안경 10종]
동그란 안경, 사각 안경, 타원 안경, 캣아이 안경, 하트 선글라스, 별 선글라스, 무테 안경, 두꺼운 뿔테 안경, 하금테 안경, 스포츠 고글.

[소품 10종]
별 브로치, 하트 배지, 리본 타이, 짧은 스카프, 펜던트 목걸이, 미니 크로스백, 미니 백팩, 허리 파우치, 어깨 위 작은 새 인형, 짧은 케이프.

[상의 10종]
기본 티셔츠, 줄무늬 긴팔 티셔츠, 맨투맨, 후드티, 앞이 열린 후드 집업, 니트 조끼, 카디건, 바시티 재킷, 바람막이, 투명 레인 재킷.

[하의 10종]
데님 반바지, 면 반바지, 카고 반바지, 트레이닝 쇼츠, 조거 팬츠, 와이드 팬츠, 체크 파자마 바지, 플리츠 스커트, A라인 스커트, 벌룬 팬츠.

[신발 10종]
로우탑 스니커즈, 하이탑 스니커즈, 러닝화, 로퍼, 메리제인, 앵클부츠, 레인부츠, 샌들, 슬리퍼, 털 실내화.

위 구성은 서로 다른 스타일을 섞어 입는 재미가 나도록 제작한다.
한 세트를 맞춰야만 자연스럽고 다른 조합은 깨지는 구조로 만들지 않는다.

각 부위에서는 하나만 착용할 수 있고, 다른 부위의 선택은 독립적으로 유지한다.
상의 때문에 하의가 자동으로 바뀌거나 모자를 바꾸면 안경이 해제되는 식의 동작은 만들지 않는다.


3. 캐릭터와 아이템의 디자인 방향

현재 앱의 어두운 배경, 스모크드 글라스, 절제된 핑크 포인트를 유지한다.

캐릭터의 둥글고 짧은 팔다리에 맞춘 전용 의상을 만든다.
일반적인 사람의 옷을 작게 줄여 얹거나, 이모지와 UI 아이콘을 붙이는 방식은 사용하지 않는다.

모든 아이템은 다음 기준을 공유한다.
- 비슷한 외곽선 강도와 디테일 수준
- 일관된 빛 방향과 그림자
- 과하지 않은 그라디언트와 하이라이트
- 모바일 크기에서도 구분되는 실루엣
- 캐릭터의 둥근 형태에 어울리는 부드러운 곡선

천, 니트, 금속, 가죽, 투명 소재 등은 구분하되 서로 다른 그림체처럼 보이지 않게 한다.
모든 아이템을 핑크색이나 네온으로 만들지 않고 차콜, 크림, 데님, 파스텔 등의 색을 조화롭게 사용한다.

의상이 몸의 액체를 일부 가리는 것은 허용한다.
다만 캐릭터 전체가 불투명한 다른 캐릭터처럼 바뀌지 않게, 얼굴과 노출된 몸의 유리 질감을 유지한다.
열린 앞섶이나 투명 소재가 어울리는 의상은 그런 디테일을 활용하되 모든 옷을 강제로 반투명하게 만들지는 않는다.

카페인 수치는 의상에 가려지지 않는 별도의 정보로 유지한다.
꾸미기 때문에 액체 높이나 카페인 상태를 실제 값과 다르게 표현하지 않는다.


4. 홈에서 꾸미기로 진입하는 방식

캐릭터 근처에 작은 옷걸이 아이콘과 ‘꾸미기’ 버튼을 제공한다.
기존 화면의 분위기를 해치지 않으면서 발견할 수 있는 정도로 표현한다.

캐릭터를 누르는 기존 동작을 꾸미기 진입으로 바꾸지 않는다.
기존 발광 반응과 카페인 추가 컵 버튼도 그대로 유지한다.

꾸미기 버튼은 카페인 수치, 추가 버튼, 흡수 안내와 겹치지 않아야 한다.
좁은 화면에서도 버튼들이 분리되어 눌리도록 한다.

하단 내비게이션에 새 탭을 추가하지 않고, 홈에서 전용 꾸미기 화면으로 진입한다.


5. 꾸미기 화면의 구성

화면은 다음 순서로 구성한다.

상단:
뒤로가기와 ‘캐릭터 꾸미기’ 제목.

미리보기:
현재 카페인 상태의 캐릭터와 선택 중인 아이템을 충분히 크게 보여준다.
홈과 같은 캐릭터 표현을 사용하고 옷장 전용으로 다른 캐릭터를 만들지 않는다.

부위 선택:
모자 / 안경 / 상의 / 하의 / 신발 / 소품.
좁은 화면에서는 부위 선택 영역을 가로로 넘길 수 있게 한다.

아이템 목록:
선택한 부위의 10개 아이템과 ‘착용 안 함’을 보여준다.
실제 착용 모습과 일치하는 아이템 썸네일, 이름, 선택 상태를 제공한다.
기본적으로 3열 그리드를 사용하되 화면 크기와 글자 확대에 맞게 조정한다.

하단:
‘모두 벗기기’와 ‘적용하기’를 제공한다.

아이템 목록을 스크롤하면서도 미리보기를 확인하기 쉽게 구성한다.
작은 화면에서는 고정 영역이 목록을 지나치게 압박하지 않도록 조정한다.

선택된 아이템은 포인트 테두리와 체크 표시 등으로 구분한다.
선택 여부를 색상만으로 전달하지 않는다.
버튼은 누르기 충분한 크기로 만들고, 한국어 접근성 이름과 키보드 조작도 지원한다.

이미 선택한 아이템을 다시 눌렀다고 해제하지 않는다.
해제는 명확하게 ‘착용 안 함’으로 처리한다.


6. 선택, 적용, 취소의 동작

꾸미기 화면에 들어오면 현재 저장된 착용 상태를 불러온다.

아이템을 선택하면 미리보기에 즉시 반영한다.
하지만 ‘적용하기’ 전에는 실제 저장된 착용 상태를 변경하지 않는다.

같은 부위의 다른 아이템을 고르면 그 부위만 교체한다.
‘모두 벗기기’는 모든 부위의 미리보기를 비우되 자동 저장하지 않는다.

‘적용하기’를 누르면 현재 선택을 저장하고, 성공했을 때 홈으로 돌아가 변경된 모습을 보여준다.
변경된 내용이 없으면 적용 버튼을 비활성화한다.

적용하지 않고 화면의 뒤로가기, 브라우저 뒤로가기, 토스 뒤로가기로 나가면 미저장 선택을 버린다.
MVP에서는 변경사항 확인 팝업을 추가하지 않는다.

저장에 실패하면 선택 중인 모습을 유지하고 실패 안내와 재시도를 제공한다.
성공하지 않았는데 적용됐다는 메시지를 보여주거나 홈으로 이동하지 않는다.

빠르게 여러 번 눌러도 중복 저장되지 않게 한다.
화면을 떠난 뒤 늦게 완료된 저장 응답 때문에 엉뚱한 화면으로 이동하지 않게 한다.


7. 개발 방식: 부위별 SVG 레이어 합성

기존 React와 SVG 기반 캐릭터 표현을 활용한다.
새로운 3D 엔진이나 게임 엔진을 도입하지 않는다.

완성된 착용 조합마다 이미지를 만드는 방식이 아니라,
기본 캐릭터와 선택된 아이템을 하나의 SVG 좌표계에서 합성한다.

예를 들어 모자, 안경, 상의를 각각 선택하면 해당 아이템의 그래픽만 조합한다.
전체 조합을 미리 제작하거나 조합별 조건문을 계속 추가하지 않는다.

아이템별 그래픽은 SVG 기반으로 구현하고, 기존 기술 환경에 맞는 방식으로 관리한다.
반드시 아이템마다 독립된 SVG 파일을 만들 필요는 없다.

아이템의 이름과 부위 등 정보, 현재 장착 상태, 그래픽 표현은 역할을 구분한다.
새로운 아이템을 추가할 때 기존 조합 전체를 수정하지 않아도 되는 구조로 만든다.
다만 이번 기능을 위해 지나치게 복잡한 범용 아바타 엔진을 만들지는 않는다.

[위치와 움직임]

아이템은 화면의 임의 픽셀 위치에 떠 있는 장식이 아니라, 캐릭터의 머리·얼굴·몸통·발 위치에 부착된 것처럼 표현한다.

몸에 부착되는 아이템은 앞쪽과 뒤쪽 모두 캐릭터의 공통 움직임을 따라야 한다.
캐릭터가 늘어나거나 기울고 떠 있을 때 옷만 떨어지지 않게 한다.

액체의 물결과 기울기는 몸 안에서만 움직인다.
옷이나 모자가 액체 수면을 따라 회전하거나 이동하면 안 된다.

[앞뒤 관계]

몸, 옷, 얼굴, 모자, 안경, 가방끈, 소품, 팔과 컵의 앞뒤 순서를 관리한다.
필요한 아이템만 앞부분과 뒷부분으로 나눈다.

예를 들어 백팩 본체는 몸 뒤에, 어깨끈은 앞에 보이게 한다.
모자나 신발처럼 몸 밖으로 나오는 부분을 몸통 윤곽으로 잘라버리지 않는다.

[자세 변화]

평상시 자세와 컵을 들고 있는 자세를 모두 지원한다.
팔을 들 때 상의의 소매와 관련 소품도 그 자세에 맞게 표현한다.

이를 위해 필요한 아이템에는 자세별 부분 표현을 추가할 수 있다.
이것은 ‘상의와 모자 조합별 이미지’가 아니라 ‘같은 아이템의 자세 대응’으로 처리한다.

자세가 달라졌다고 사용자가 고른 옷을 숨기거나 자동 해제하지 않는다.
이번 소품에는 별도의 손에 드는 컵을 추가하지 않고 기존 컵 표현을 유지한다.

[성능과 기존 동작]

아이템 선택으로 캐릭터 전체를 매번 새로 만들거나 액체 움직임을 초기화하지 않는다.
아이템 목록의 썸네일은 정적인 그래픽으로 표시한다.
60개 아이템마다 캐릭터 애니메이션이나 기기 센서를 실행하지 않는다.

홈과 미리보기, 여러 썸네일이 함께 표시돼도 SVG의 색상·마스크 정의가 서로 간섭하지 않게 한다.

기존 백그라운드 정지, 동작 줄이기, 센서 권한 정책을 유지한다.
꾸미기 진입이나 아이템 선택만으로 새로운 센서 권한을 요청하지 않는다.


8. 저장과 기존 데이터 보호

현재 프로젝트의 저장 방식을 재사용한다.
꾸미기를 위해 별도의 서버나 계정 체계를 추가하지 않는다.

부위별로 어떤 아이템을 착용했는지 식별 정보만 저장한다.
완성된 캐릭터 이미지나 SVG 전체를 저장하지 않는다.

기존 사용자에게 착용 정보가 없다면 아무것도 입지 않은 상태로 시작한다.
저장한 모습은 홈 재진입과 새로고침 후에도 유지한다.

알 수 없는 아이템이나 잘못된 부위 정보가 있으면 해당 부분만 안전하게 해제한다.
아바타 정보의 오류 때문에 기존 카페인 기록 전체를 지우거나 앱 사용을 막지 않는다.

꾸미기 저장은 착용 상태만 변경해야 한다.
기존 음료, 섭취 기록, 사진, 카테고리, 설정을 변경하거나 이전 값으로 되돌리지 않는다.

카페인 계산 방식, 기존 기록 추가·수정·삭제 기능은 이번 작업 범위 밖이다.


9. 완료 기준

다음 상태가 모두 충족되어야 완료다.

- 6개 부위에 실제 착용 가능한 아이템이 각각 10개씩 있다.
- 색상만 바꾼 복제가 아니라 형태와 스타일이 구분된다.
- 모든 아이템에 실제 착용 그래픽과 일치하는 썸네일이 있다.
- 부위별 선택, 교체, 해제, 전체 해제가 동작한다.
- 적용 전 미리보기와 저장된 착용 상태가 구분된다.
- 적용 후 홈과 재진입 시 같은 모습이 유지된다.
- 저장 실패와 취소 시 기존 데이터가 보호된다.
- 평상시와 컵을 든 자세에서 의상과 팔이 자연스럽게 연결된다.
- 카페인 상태가 바뀌어도 아이템이 떨어지거나 잘리지 않는다.
- 기존 캐릭터 반응, 액체 표현, 카페인 기록 기능이 유지된다.
- 작은 모바일 화면과 글자 확대에서도 조작할 수 있다.

모든 착용 조합을 전수 검사할 필요는 없다.
대신 60개 아이템을 각각 확인하고, 모자와 안경, 상의와 소품,
하의와 신발 등 간섭 가능성이 높은 조합을 집중적으로 검증한다.

검증에는 아무것도 입지 않은 상태, 전체 부위 착용 상태,
서로 다른 스타일을 섞은 상태, 여러 카페인 상태와 자세를 포함한다.

기존 캐릭터를 다른 모습으로 교체하거나, 준비되지 않은 아이템을
이름만 나열하는 것으로 완료하지 않는다.

먼저 기존 구현을 확인하고 이 기획을 적용할 개발 방향을 짧게 설명한 뒤,
실제 기능과 아이템 제작, 동작 검증까지 진행해줘.
