## 변경

- 즉시 흡수 근사를 1구획 1차 흡수·제거 모델로 교체. 제거 반감기 5h, 흡수 속도 4.54/h, F=1.
- 각 섭취 시각별 흡수된 잔존량을 합산. 흡수 전 양은 별도로 관리하고 홈 mg에 합치지 않음.
- 홈·음료 목록·예측에 같은 식 사용. 새 기록은 `흡수 중` 표시, 초기 상승 곡선은 그래프 범위에 포함.
- 설정 수식·변수 설명 갱신. 원래 기록, 저장 스키마 v2, 체감 설문의 PK/PD 분리 유지.
- 375px에서 흡수 안내 추가로 예측 카드가 고정 버튼에 일부 가려진 문제를 여백 조정으로 해결.

단위 테스트는 구현의 지수식과 별도로 미분방정식을 RK4 적분해 대조한다. 섭취 순간, 초기 상승·이후 감소, 섭취 시각별 중첩, 미래·손상 기록, 자정 연속성, 동일·유사 흡수/제거 속도, 장시간 경과, 질량 보존을 확인했다. 기존 즉시 흡수 구현에서 새 도메인 테스트가 실패한 것을 확인한 뒤 구현했다.

브라우저에서는 150mg 기록 직후 0mg+흡수 안내, 30초 자동 갱신 후 6mg, 30분 뒤 128mg, 1시간 뒤 133mg, 1시간 30분 뒤 126mg을 확인했다. 미래 기록이 예측에 포함되지 않고 새로고침 후 원래 데이터가 유지되는 것도 검증했다. 목록에 숨긴 1mg 미만의 잔존량도 전체 mg 계산에는 포함된다.

기존 음료 기록·미세 조절·커스텀 음료·수정/삭제·새로고침·설문·달력·뒤로가기 흐름과 다크/라이트·글꼴 200%·수식 지수/분수 배치를 확인했다. 실제 로컬 미리보기 `localhost:5174`에서도 기존 기록이 유지된 상태로 홈과 설정의 새 설명·수식을 확인했다. 사용자 데이터에 테스트 기록을 추가하지 않았다.

이 문서는 코드와 UI의 검증 결과다. 개인의 실제 잔존량, 흡수 속도, 반감기 또는 임상 예측 정확도의 검증 결과는 아니다. [모델 가정·한계](./research/oral-caffeine-model.md).
